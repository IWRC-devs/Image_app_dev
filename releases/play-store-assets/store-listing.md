```
Capture weed-ID photo batches in the field — saved locally, nothing uploaded.
```

## Full description (max 4000 characters)

```
IWRC Imaging is a field data-collection tool for capturing structured weed-identification photo batches — built for researchers and technicians working on-site.

HOW IT WORKS
For each batch, the app walks you through:
• Location (country / state)
• Plant and site parameters (botanical name, weed site, background, growth stage, soil color, lighting)
• Photos — capture with the camera or select existing images
• Review and save

Each saved batch is written to a folder you choose on your own device, as a set of image files plus a plain-text file listing the batch details — easy to browse, copy, or back up with any file manager.

PRIVATE BY DESIGN
• No account or sign-in required.
• No internet connection used or required — the app has no backend server.
• No analytics, no advertising, no trackers.
• Your photos and batch data never leave your device unless you move them yourself.

WHO IT'S FOR
Built for IWRC (weed research) field teams who need a consistent, repeatable way to document weed specimens on location without relying on cloud storage or connectivity.

PERMISSIONS USED
• Camera — to take photos within the app.
• Storage (folder access) — to save your batches into a folder you choose.
No other permissions are requested.
```
